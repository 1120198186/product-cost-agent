# 外壳、质量与工艺定制模型

无实物时也主动估质量：查整机净重/重量上限、尺寸和图像，核对是否含包装线缆；估本项结构体积×适用材料密度，结合壁厚、空腔及主要其他部件做质量平衡/上限检查。不把整机重量上限当精确值相减，不把空心壳按实心体积计算，不重建完整质量BOM。区分资料事实、尺寸/壁厚/密度假设及范围。

普通一级注塑成本项：`C=m×K综合`。K为与材料、结构、批量及工艺匹配的单位净质量综合系数；低比例开模影响可以包含其中，不另行精细追算和重复叠加。

若用户输入本身就是需开模的注塑产品（如机器人胸腔外壳）：`C(Q)=m×K不含模具 + F模具/Q`；另列模具总额、寿命/产量分摊条件及有依据的Q。工艺费系数已含哪部分必须写清。批量遵循当前任务，不默认1K/10K。

K优先来自经确认且适用的企业经验资产、范围明确的采购/报价反算，再查公开材料价、加工计费及设备工时信息建立透明工程系数。使用范围包括材料、工艺、复杂度、尺寸/质量、批量、税运、是否含模具/利润；不能宣称存在万能行业系数。系数无实价时可给有依据的情景及敏感性，不以精确品牌现价作为唯一前提。

材料/工艺未确认就保留合理条件路线。金属外壳不可套塑料系数，浸塑不得当注塑；不为便宜将CNC擅改压铸。不用完整相机售价或不匹配普通盒子售价替代模型。按冻结范围保留紧固件等包含项；包内制造和整机装配分别排重。

真实参数价与反算/经验系数分开。历史公司披露只能作有日期、有范围的案例，不能把其中损耗、利润或加工系数永久写成默认常数。计算质量和K各自变化对区间的影响，避免把不相容极端组合成所谓最可能成本。
