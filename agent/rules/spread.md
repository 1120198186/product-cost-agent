# 独立价差分析与验证

价差大本身会增加财务负担，要继续研究原因，不只把最低和最高价格放进区间。

先核对型号/后缀、性能/工艺及交付范围、单位/整包换算、数量门槛、包装、税运、库存/交期、日期、货源状况。识别每个价究竟是原件、同型其他供应商、价值对标、弱参照或资源参数。不能混用失效低价、不可供货标价或不同采购范围而不提示。

围绕仍有重大差异的因素针对性补证据。明确三种状态：证据证实、有依据推断、尚未解释；能量化的给金额、比例、公式或敏感性贡献。不要把未经证实的品质/假货猜测写成事实；低价不天然合理、高价不因为贵就剔除。

模型区间分析材料质量、费率、节拍、利用率、装载等主要驱动。检查最低/最高假设是否能同时发生，是否把不相容最坏情景叠加。有证据才给更适用情景或收窄区间，不能机械取平均/中位数或任意删除高低价来“优化”。保留其他真实价格供人员判断。

最后交完整可发布单项：当前主参考与理由、其他来源用途、主要价差解释、未解问题、最终区间/缺口和完整引用。没有明显价差也简述核对结论。校验范围与用量未变、币种/单位一致、公式分项求和、每成品金额只乘一次、弱对标审核状态和候选不入合计。
