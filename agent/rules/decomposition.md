# 第一步：可累计的成本拆分

先核实公司、产品型号、版本、标准交付内容及用户先验。优先原厂产品页、规格书、官方图片/框图，矛盾和无法证实的信息明确保留。

拆的是成本组成。一级组成是画图分组，不计价；一级成本是可以独立采购、取得价格或用稳定方法估价的工业单品/标准采购包。广角成像模组可以作为分组，镜头、CMOS各是可计价子项。不完整追拆每颗阻容、每个螺丝；必要小料合并为有明确范围的包。不同时核算总成及已列内部件。

在这里一次明确数量（或有依据范围/未知）、采购包含/排除、已含关系及独立计价边界。如镜头的镜筒/镜座/滤光片、板卡排除哪些单列核心器件、是否包含板级贴装检测。后续阶段承接而不重拆。

每项识别实装型号、原厂、实际供应商，并区分已证实与参考。查找路径：型号+供应商 → 准确型号 → 同类工业单品 → 价值/功能对标 → 性能参考。找不到实装信息不等于没有参考；可以提供明确标注的参照，但不能写成实装身份。自研、采购范围、关键规格、差异和依据均记录。工艺定制采购包说明可用于估价的功能/材料/结构线索，后续走模型，不强求找到一个整件售价。

工艺指购入组件/物料形成可交付标准成品的关键增量加工，不列采购已含的制板、芯片封装、镜头制造等上游工艺。区分资料明确的工艺、按完整标准工艺有依据推定的工序，以及条件候选。前两类可有依据采用，候选保留状态；采用关系在此完成。清洗、锁附、预固化、固化等按稳定成本驱动合理归并，不追溯所有低额动作，不堆不相关工艺。

固定三类颜色：部件、成品工艺、利管销研发。固定保留利润、管理、销售、研发四项，不意味着比例固定；这四项不需要介绍。

每个部件/工艺有局部图、图源、图注及在此产品中的用途。优先实物或局部图；功能示意和整机定位图明确标注，不把类似产品图冒充实物。未知/推断不能装成确定参数。节点存在的确认程度与参考型号是否实装是不同字段。

先规划，再拆分，最后独立验证层级、数量/范围、排重、完整关键工艺、证据及身份。输出 `assets/schemas/decomposition.schema.json` 所示结构，不输出金额。示例图仅为呈现参考，不是新产品的BOM模板。
