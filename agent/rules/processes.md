# 第三步：成品增量工艺估价

只为第一步已有工艺定价，不重判必要性。消费原状态和采购包含范围；明确有的和完整工艺推定有的工序都可按原采用关系估价。未启用/候选工艺同样给执行条件价，保留未计入主合计；待核不等于零。

依次尝试三条路径：①同加工范围的直接真实报价；②人工、设备、耗材、循环批处理的资源模型；③缺部分精确数据时有依据的工程情景。先实际检索①并记录结果，不能假装已有加工价。没有精确同品牌设备/胶料价，继续研究适用同类资源、公开历史交易、级别/机时费和工艺资料，不只交人工小计或“待询价”。确实没有任何可支持范围的依据再留缺口。

资源模型不要求原厂采用同一具体设备或胶水；只要适用性有论证，未知参数可透明估计。未确认原厂设备品牌不触发弱商品对标审核门。反之明显不适用的设备/材料不可借模型标签混入。RFQ不是价格，设备价/耗材价不是每台成品加工报价。

人工用人秒（人数×作业时间），设备用实际占用时间，不把机器无人等待全算人工。设备综合费率涵盖正常折旧、维护和有效利用率，资本不全部压到当前订单；若已用综合机时率，不再重复电力/维护。工资统计、企业负担和有效工作小时分别说明。有效装载率、批容量、向上取整批次及循环费用按 `quantity.md`。用量/节拍/产能/稼动率不得默认为该工厂实测。

已计在第二步的SMT、板级检测、壳体制造排除；成品工艺之间也按范围排重。AA闭环对准不自动等于出厂几何内参标定。基础为正常加工，额外返工/报废制造增量单列敏感性，物料报废影响不回写采购单价。利管销研另留。

每项独立规划→必要参照研究→参数取价/计算→价差分析。多数工艺无需单独对标轮，只有参照适用性确实需要专门研究才增加。展示直接报价是否查到、选用路径、资源分项和主要驱动。费率与工时是本项目假设或有条件资产，不把某相机的秒数固定到所有产品。
