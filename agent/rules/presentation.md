# 固定模板与人工审核

复用 `assets/web/`，数据填充，不每次重新生成整套HTML。三类颜色保持一致；一级组成分组不计价，一级成本才累计。唯一主视图是关系图，点缩略图在图内弹出部件/工艺成本详情，不另建第二个产品成本主页面。

首层显示区间、口径、关键限制；部件介绍附近显示方法及理由、取价对象、对标理由和关键差异、真实来源价格。价格按中国/中国以外及企业归并；折叠层呈现阶梯、包装、税运、日期、质量标记和详细链接。价差解释需可见，深层再放公式、参数、完整证据、提示词与阶段结果，删冗余重复叙述，不删关键证据。

人工采用区间、币种及采用依据独立保存；不修改研究区间。未知、部分覆盖、候选执行成本与已采用费用清楚区分。已估小计不是完整成本，利管销研未估不假装已含。

归档保存可读HTML副本及原JSON/MD。外部网站需联网；产品图片未归档时明确展示来源/缺图状态，不冒用其他部件图片。离线审核数据保存到浏览器，需要导出JSON发回，换版本须复核，CSV仅用于表格阅读。
