# 来源投入分配

基于冻结的成本项，对成本占比作粗略先验判断，用于重要性及推荐来源数量，不是正式估价。只按占比分配，不按不确定性加权；不要将这些粗估金额或份额作为后续定价锚点。

输出 shares：每个本轮部件/工艺ID对应 share（0到1）、basis（粗估理由）、recommendedSources=max(3,round(100×share))。份额允许近似，但说明基准范围，归一到本轮预计部件与工艺成本。自研/待审不直接当零。来源目标不是找不到就失败的门槛。

宿主只把当前项的推荐条数与“仅为搜索目标”说明交给其研究回合，不传其他项金额推测或研究过程。当前任务已有用户明确来源数时沿用并说明。
