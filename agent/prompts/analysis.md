# 独立价差分析与最终验证

以本项价格/模型结果为起点，按需补查证据。不要只接受前轮可比标签或机械取极值。检查原件优先、价值与交付范围、数量/包装/日期/税运等；针对大价差给具体可核原因，区分证实、推断和未解。量化主要驱动，检查模型情景相容性，不能无据取平均、删贵价或缩窄区间。

提交完整最终单项JSON，不只交审阅意见。解释主区间为什么这样取、每条价格/情景作用、仍未解决什么。原始报价和来源保留，必要修正据新证据说明。核验冻结快照、包含关系、币种、数量、分项求和、每成品用量只乘一次和弱对标批准状态。无价差也给简短核对说明。

此轮完成后由宿主进行机械校验与展示，候选/未估/部分覆盖不伪装完整总价。可以交付明确的条件模型，不因普通工程不确定性人为增加审批门；弱商品对标则仍保留成本人员审核。
