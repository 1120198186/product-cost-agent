# 必要的参照研究

只解决取价对象/资源方案的适用性。原件/准确型号可用时优先原件；商品化部件选最接近的1–2个主要目标，研究价值相关性能、工艺及采购范围，初查真实价格是否可获得。技术最近但无价时继续查渠道或同平台同规格的适用对象，不以无价候选作为终点，也不为有价放宽可比性。

结果包含 nodeId、selectedTargets（对象、关系、理由、差异、来源）、comparisonGate、priceLeads、rejectedCandidates、evidence、handoff。只能弱对标时 needs_review，保留真实参照，不能替人批准。资源模型的原厂设备身份未知不自动触发这个门。此轮不进行最终全量定价。
