# 接手后的效果验收

本仓库已经保存完整规则与可执行的模板/上下文工具；实际研究效果还取决于宿主给到的模型、推理配置、联网/读图能力以及可获得证据。代码检查不能保证估值接近真实采购。

建议平台首次用一个已知成本产品验收，覆盖商品部件、定制板卡/壳体和成品工艺；不要把合成示例当效果案例。

1. 检查执行记录：第一步实际三次调用，每异质成本项规划/必要对标/估价/价差分析分别调用，模型/推理继承真实，无逐轮主审或整段上下文污染。
2. 检查目标：冻结项是否完整承接，已有同型号原件价格是否先采用，有价的替代品是否误替代原件，主要费用是否得到可复核估计。
3. 抽查最重要成本项的原始网页、阶梯、数量/包装/币种、型号可比性及企业去重；按条数完成不等于价格准确。
4. 检查定制包：质量/面积/工时假设可追溯，模型费用完整且排重；无精确参数时有合理情景，而不是无故停在待询价。
5. 检查弱对标仅影响本项目标采用；无批准留空，有批准按独立记录恢复该项，其他项目不停工。
6. 检查大价差说明是否真正减少成本人员判断负担：主驱动、可量化影响、证实/推断/未解分别清楚，区间不被人为压窄。
7. 检查关系图的每个详情、人工保存和导出发回；所有归档链接能打开，候选与未知不被计成零或完整总价。

将实际成本/报价反馈保存为带范围的校准记录；需要修改业务规则时更新规则版本和本表，不通过塞入更多重复提示词解决所有偏差。
