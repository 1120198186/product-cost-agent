此表用于交付复检，不作为每个子回合的额外上下文。

| 估算成本是目的，流程服务目的，避免无意义约束 | AGENT、common；允许据新证据调整研究方法 |

| 固定模板与可变流程规则分开，后续有知识资产 | README、knowledge、assets；原案例不升为常量 |

## 已被后续要求替代的旧规则

- 不再采用每项固定十来源、厂商/电商来源比例。
- 不再强制所有估价都输出1K和10K；只在用户指定数量时按该量处理。
- 不把每个阶段交给主线程审阅，不把一轮长回答分标题当独立推理。
- 不在第二/三步重拆一级成本、重新判工艺必要性，不让弱对标价直接混入目标金额。
- 不把森云或其他案例的重量、板层、系数、工时、费率和源条数当通用默认。
